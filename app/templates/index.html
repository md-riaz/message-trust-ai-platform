API Documentation

POST /analyze

Analyze multiple messages at once. Pass an array of messages with IDs.

{
  "messages": [
    { "id": "1", "content": "Sample message text" }
  ]
}

Response:

{
  "results": [
    {
      "id": "1",
      "content": "Sample message text",
      "prediction": [
        { "label": "__label__clear", "probability": 0.99 }
      ]
    }
  ]
}
